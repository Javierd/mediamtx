MediaMTX MSE Player Example

Usage:

  1. Enter the WebSocket URL for your stream (e.g., ws://localhost:8890/mystream)
  2. Click "Connect" to start streaming
  3. The player will automatically retry connections on errors
  4. Click "Disconnect" to stop the stream

Example with JavaScript API:

// Create a new MSE player
const player = new MediaMTXMSEPlayer({
  url: 'ws://localhost:8890/mystream',
  videoElement: document.getElementById('myVideo'),
  onError: (err) => {
    console.error('MSE Player error:', err);
  }
});

// Later, close the player
player.close();
